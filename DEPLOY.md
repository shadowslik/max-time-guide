# Как обновить фронт (мини-апп) на хостинге


## Обновление в 2 команды

Всё делается из папки `frontend`. Поменял код → пересобери → задеплой:

```bash
cd frontend
npm run build
npx wrangler deploy
```


## Первый запуск (один раз на компьютере)

При первом `npx wrangler deploy` откроется браузер — нужно **войти в Cloudflare**:

```bash
npx wrangler login
```

> ⚠️ **Важно:** деплой уходит в тот аккаунт Cloudflare, под которым ты залогинен.
> Чтобы обновлять **именно этот** адрес (`...ovoaookaaooaoa.workers.dev`), нужно быть
> в аккаунте, которому принадлежит проект. Если залогинишься под своим личным
> аккаунтом — создастся **другой** воркер с другим URL.
>
> Поэтому либо деплоит владелец аккаунта, либо он приглашает тебя в проект
> (Cloudflare → Manage Account → Members). Уточни у владельца перед первым деплоем.


## Правила

- Команды запускать **только из папки `frontend`** (не из корня репозитория).
- `dist/` и `node_modules/` **не коммитим** — они в `.gitignore`.
- Перед деплоем убедись, что локально всё работает: `npm run dev` → открой http://localhost:5173.
- Если `npm run build` падает — сначала почини сборку локально, деплоить сломанное нет смысла.
