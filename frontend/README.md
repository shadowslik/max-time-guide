# Рядом — навигатор досуга по свободному времени

Фронтенд mini-app для решения на платформе **MAX** (чат-бот + mini-app) в рамках
трека «Досуг и развлечения». Это чистое mini-app без стенда и обвязки: то, что
открывается из чат-бота.

> Данные о местах приходят с бэкенда вживую из **2ГИС** (по всей РФ); адрес и
> часовой пояс — из **DaData**. Небольшой набор по Казани в `data/places.js` —
> офлайн-фолбэк и демо-история, помечен как тестовый.

## Идея

Человек в командировке / проездом получает свободный час-другой в незнакомом городе.
Вместо «вот 20 достопримечательностей рядом» продукт спрашивает: **сколько у тебя времени** —
и показывает только те места, куда реально успеть сходить **и вернуться**, с учётом дороги
туда-обратно и запаса времени.

Формула проблемы: *турист/командированный в чужом городе со свободным окном 1–3 ч хочет
провести его с пользой, но тратит время на поиск и не знает, что успеет, — и в итоге не идёт никуда.*

## Основной пользовательский сценарий

1. **Чат-бот MAX** — приветствие, кнопка «Найти, куда сходить» открывает **mini-app**.
2. **Точка старта** — пользователь ставит метку на карте: автоматически геопозицию
   не определяем, поэтому от метки и считаем всё остальное.
4. **Сколько времени** — ключевой экран с визуальным «бюджетом времени» (дорога · на месте · запас).
5. **Интересы** — быстрый выбор (можно пропустить).
6. **Подбор** — экран, показывающий, что продукт считает под капотом.
7. **Результаты** — интерактивная карта с метками; тап по метке → карточка с раскладом времени
   и статусом 🟢 Успеваешь / 🟡 Впритык / 🔴 Не успеешь.
7. **Маршрут** — таймлайн «выход → дорога → место → возвращение» и открытие в Яндекс.Картах.
9. **Цепочка** — если после одного места остаётся запас, собираем маршрут из двух.
10. **Ничего не успеть** — честный фоллбэк с ближайшим вариантом и кнопкой «+30 минут».
11. **Изменить** — быстрая правка времени и интересов поверх результатов.
12. **Мой профиль** — аватар и имя из MAX, статистика и история просмотренных маршрутов (открытие маршрута из истории строит его заново от точки старта).

## Стек

- **React 19** + **Vite 5**
- **MapLibre GL** — интерактивная карта. Векторные тайлы OpenFreeMap, ключ не нужен.
- **OpenRouteService** — геометрия пешего маршрута. Ключ бесплатный, по желанию.
- Данные о местах — с бэкенда (2ГИС/DaData); ключи этих сервисов на бэкенде, не во фронте.

## Запуск

```bash
npm install
npm run dev
```

Приложение поднимется на `http://localhost:5173`. Сборка прод-версии:

```bash
npm run build
npm run preview
```

Через Docker — из корня репозитория: `docker compose up --build`, всё приложение
(фронт + API за Caddy) будет на `http://localhost`.

## Ключи

Оба необязательные — без них приложение полностью работоспособно.
Шаблон в `.env.example`, значения кладутся в `.env.local` (или в корневой `.env`,
если запускаете через docker-compose).

| Переменная | Зачем | Без неё |
|---|---|---|
| `VITE_ORS_API_KEY` | пешие маршруты по улицам | линия рисуется прямой |
| `VITE_MAPTILER_KEY` | векторные тайлы с тёмной темой | растровые тайлы OSM, тёмная тема — инверсией |

Ключ OpenRouteService бесплатный, нужна регистрация: 2500 запросов в сутки,
40 000 в месяц на все сервисы вместе.

Тайминги подбора **никогда** не зависят от сети: их считает собственный
планировщик (`src/lib/planner.js`). Маршрутизатор влияет только на геометрию
линии, поэтому демо предсказуемо даже без интернета.

## Как считается время

Пользователь ставит метку на первом экране — от неё и пляшет вся арифметика.
Расстояние до места берётся по формуле гаверсинуса, умножается на 1,3
(по улицам идёшь длиннее, чем по прямой) и делится на скорость 4,8 км/ч.
Фиксированных «сколько идти» в данных нет: передвинул метку — пересчиталось всё.

Дальше для каждого места сравнивается
`дорога туда + время на месте + дорога обратно + запас (10 мин)`
с доступным временем (`src/lib/planner.js → evaluatePlace`):

- **Успеваешь** (зелёная метка) — хватает на комфортный визит;
- **Впритык** (жёлтая) — успеваешь при сокращённом визите;
- **Не успеешь** (серая) — не хватает даже на минимальный; место остаётся на карте с пометкой.

`buildChain` перебирает пары подходящих мест, считает переход между ними
и выбирает пару, где суммарно больше времени «на месте» в рамках бюджета.

## Структура

```
src/
  App.jsx                   # состояние поездки и навигация между экранами
  data/places.js            # тестовые данные: места, интересы, история, опции времени
  lib/
    planner.js              # evaluatePlace / pickPlaces / buildChain — ядро подбора
    geo.js                  # расстояния и время пешком
    router.js               # маршруты через OpenRouteService
    mapStyle.js             # стиль карты: OSM или MapTiler
    format.js               # время, длительности, склонения
    maxBridge.js            # тема и внешние ссылки через окружение MAX
  components/
    MapCanvas.jsx           # карта MapLibre: метки, линия маршрута, кадрирование
    MapPin.jsx              # метки-капли
    Sheet.jsx               # шторка снизу, которую можно тянуть
    ScreenStack.jsx         # переходы между экранами и модальными шторками
    TimeBudgetBar.jsx       # полоса бюджета времени — ключевая механика
    Timeline.jsx            # таймлайн маршрута
    PlaceArt.jsx            # иллюстрация в шапке карточки места
    Icon.jsx, ui.jsx        # иконки Material Symbols и примитивы интерфейса
  styles/                   # токены тем, каркас, экраны, анимации
  screens/                  # 12 экранов сценария
```

## Тема

Своих переключателей нет: тема берётся из окружения MAX, а вне мессенджера —
из `prefers-color-scheme`. Смена подхватывается на лету, все экраны нарисованы
в обеих темах.

## Атрибуция

- Карта: © [OpenStreetMap](https://www.openstreetmap.org/copyright), лицензия ODbL.
  Контрол атрибуции MapLibre обязателен к показу и специально поднят над шторкой.
- Иконки: [Material Symbols](https://fonts.google.com/icons) от Google, Apache 2.0.
- Иллюстрация: [unDraw](https://undraw.co), свободная лицензия без атрибуции.

## Известные ограничения

- Качество и полнота мест зависят от 2ГИС; без ключа бэкенд отдаёт фолбэк из OSM.
- Время в пути — модельная оценка (гаверсинус × 1,3); реальная геометрия линии —
  только при наличии ключа OpenRouteService.
- Часы работы и рейтинги берутся из 2ГИС и могут отставать от факта.

Ядро (сценарий, логика подбора под время, структура интерфейса) переносится
в другой город/регион без изменений — меняются только данные о местах (2ГИС сам
отдаёт их по координатам старта).
